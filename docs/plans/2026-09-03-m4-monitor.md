# M4 GPU 监控页：micro-step 计划（2026-09-03）

依据：[2026-09-03 方案](../design/2026-09-03-multimodal-monitor-events-prompt.md) F3。
两个任务，一任务一提交。TDD。

## Task 1 host 侧：metrics 端点 + monitor RPC

1. `panel-client.ts`：
   - `getMetricsWindow(range, since?)`：`GET /api/v1/metrics/window?range=&since=`，
     响应 `{range, from, resolution, series, mode}`；投影只声明要画的 6 个指标键
     （infer.tokens_per_sec / infer.kv_cache_tokens / gpu.mem_used_mib /
     gpu.util_percent / container.cpu_percent / container.mem_percent），series 键
     缺席容忍（面板加减指标不炸）
   - `getGpuStats()`：`GET /api/v1/gpu/stats` → `{available, status, devices, totals}`
2. `rpc-contract.ts`：`monitor(range, since?)` 方法 + RANGE/SINCE 形参 + cancellation
   signal；`MonitorSnapshot` 类型 + strict codec（series 指标点数组、gpu 设备明细、
   mode、panelError）
3. `panel-gateway.ts`：monitor 实现（metrics+gpu 并发 allSettled，失败走 panelError
   不抛——页面要能画「连不上」；signal 透传给两个端点）
4. 单测 + E2E（fake panel 加两个假端点）

## Task 2 client 侧：MonitorPage 整页

1. `src/client/Sparkline.tsx`：纯 SVG 折线（viewBox 自适应、末点高亮、无交互）
2. `src/client/MonitorPage.tsx`：range 切换（30m/2h/24h/7d）+ 运行模型标题 + 三卡
   （tokens/s & KV cache / GPU 显存 & 利用率 + 分卡温度功耗 / 容器 CPU & 内存）；
   挂载轮询（5s，24h/7d 档 60s），首帧 full 后带 since 增量拼接；卸载清理 + abort
3. 注册 `settings.section` slot（id: llamapad-monitor, order: 60, locale），导航
   自动出现
4. locale + styles + 测试（纯函数：增量拼接、轮询间隔选择、投影折算）
